# PROJET_EXADIM_Caribou
## Consignes 
Pour étudier les associations entre la variation génétique et les conditions environnementales, des
chercheurs ont échantillonné 88 caribous (Rangifer tarandus) dans le nord de l'Amérique
du Nord, de l'Alaska au Labrador et jusqu'aux îles du Haut-Arctique canadien. Chaque
individu a été génotypé sur 6 000 marqueurs SNP, codés 0, 1 ou 2 selon le nombre de copies de
l'allèle minoritaire (fichier genotypes_caribou.csv ; les quelques génotypes manquants ont été
remplacés par le génotype le plus fréquent du marqueur).
4
Pour chaque individu, on connaît aussi les coordonnées géographiques, l'écotype (grand
type d'habitat) et huit variables climatiques et paysagères du lieu d'échantillonnage (fichier
environnement_caribou.csv, décrit dans legende_variables_environnementales.csv).
Ce sont des données réelles, mais l'espèce et certaines informations ont été modifiées pour les
besoins de l'exercice.
